# Digest

将零散资讯蒸馏成高密度主题式参考书。

## 输入

用户提供三类数据源路径：
- 订阅源（RSS、Newsletter等）
- 社群内容（星球、Discord等）
- 个人收藏（书签、笔记等）

## 蒸馏流程

两波流水线，提取与综合严格分离。

**第一波：提取**
- 按数据源类型派发Agent，每个Agent独立读取并产出结构化提取文件
- 提取粒度：单条信息 → 观点/事实/数据点
- 每条标注：信息源质量（高/中/低）、共识度（共识/分歧/存疑）

**第二波：综合**
- 按主题派发Agent，读取提取文件组装成册
- 跨源去重后合并同类项
- 输出导览摘要，生成HTML

## 产出标准

每个主题分册结构：

```
# 主题名

## 导览
> 3-5句话概括本册核心收获

## 观点汇总
### 子主题A
- 观点内容 [源: 来源名 | 质量: 高 | 共识]
  - 读后收获：...
  - 关键变量：...

### 子主题B
...
```

两种格式：
- `.md` — 留存，供后续跨月调用
- `.html` — 浏览器阅读

## 已知的坑

1. **PDF溢出** — 单个Agent精读PDF不超过5份，超出则分批
2. **去重** — 星球等内容同一信息多天重复，提取阶段必须去重
3. **覆盖率** — 提取完成后检查是否覆盖所有数据源，遗漏则补提
4. **提取综合分离** — 绝不能在同一Agent内混合，否则上下文爆炸

## 自我进化

每完成一个阶段，记录问题与解决方案到 `数据层/问题与解决.md`，格式：

```
## 日期 - 阶段名
- 问题：...
- 解决：...
- 预防：...
```
